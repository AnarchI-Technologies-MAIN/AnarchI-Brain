## Jurisdiction and independence

S1 evaluates explicitly identified candidate structure and provenance evidence against pinned qualification rules. Cartologist normalization and proposal remain M03 activities. S1 qualification is separate from truth adjudication and from the three future canonical adjudications. It cannot authorize ingress, authenticate a runtime principal, grant permissions, publish canon, issue a runtime receipt, disclose protected data, execute attachments or change an authority root. Qualification does not prove universal truth, independent corroboration or source honesty.

The proposed matrix delta grants only constitutional eligibility for bounded noncanonical qualification. Those runtime mechanisms are outside Unit A and remain unresolved. The offline reference evaluates fixtures without claiming to exercise that authority.

Dependency closure and resource budgets must be bounded; no opaque attachment is executed. ## Qualification findings and freshness

Required findings are orthogonal: subject identity, representation binding, dependency identity, structural contract conformance, provenance evidence conformance, context/freshness and conflicts. Provenance conformance retains original sources, lineage, ambiguity, contradictions and source dependence; multiple records from one source are not independent corroboration.

Freshness is evaluated against a separately supplied pinned context and the existing M08 V8r2 non-authoritative fixture decision. M08's actual fixture output is an input, not an authority grant. A stale or conflicting context is BLOCKED; missing context, unknown interpretation or an unavailable required check is UNRESOLVED. The reference cannot turn an asserted boolean, model verdict, caller label or copied SATISFIED finding into verified evidence. Matching fixture values proves finite model behavior only.

Aggregate diagnostic results are QUALIFICATION_SATISFIED when every required check within the explicitly named reference profile is satisfied, QUALIFICATION_BLOCKED when a required check fails, and QUALIFICATION_UNRESOLVED when no blocking finding exists but at least one required check is unresolved. All individual findings are retained, including unresolved findings alongside blocked findings. An unknown or missing disposition is unresolved. A satisfied structural/custody fixture does not assert completed semantic qualification of the contents: that additional content evaluation remains UNRESOLVED and undeveloped unless a later exact contract and evaluator supplies it.

All aggregate results explicitly identify profile STRUCTURE_PROVENANCE_SCOPE_ONLY and preserve content admission=UNRESOLVED, semantic resolution=UNRESOLVED, runtime crossing permission=false, canonical membership=false and operative authority=UNRESOLVED. Scope comparison verifies context identity only, not allowed access. A QUALIFIED_REFERENCE internal structural finding may be retained, but does not replace this aggregate vocabulary or transition the runtime M04 lifecycle: it remains CANDIDATE. No result is an authorization, runtime grant, canonical admission or production readiness statement. Result serialization is a diagnostic artifact rather than an M14 durable occurrence receipt.

## Idempotence, invalidation and failure

For identical pinned subject, contract, dependencies, baseline, scope/purpose, policy and freshness/conflict context, the pure evaluator returns the same diagnostic findings. This is determinism, not a persistent replay registry. Any changed coordinate invalidates reuse of a prior result and requires a new evaluation. Reusing an identity with changed bytes is a conflict, not a replacement authorized by a prior result. Revocation, expiry or an integrity/context change cannot be erased by replaying an older satisfied diagnostic.

The diagnostic result identity binds the exact six-field subject, exact fixture context and executable reference dependency set: the four fixed code pins, M04 contract pin, mapping contract pin and accepted baseline catalog pin. It does not directly bind the Unit A catalog, matrix successor or denial-table bytes. The enclosing qualification receipt separately binds that Unit A catalog and all selected nonexecuting contracts. A diagnostic result cannot be credited to a different executable binding, and package-level qualification cannot be credited to a different enclosing catalog. These identities are reference custody bindings, not persistent replay receipts, live authenticated contexts or permission to disclose prior results.

Missing inputs, parse errors, unsupported schemas, malformed bytes, resource exhaustion and failed verification create no effects. Preserve the actual prior state; do not materialize normalized/proposed/canonical bytes, issue success receipts or silently discard failures. Refusal requires no positive grant. Storage, transactional replay, crash recovery, authority enrollment and disclosure authorization are not implemented by this reference.
