# Authority Dimensions

Status: SPECIFIED, NOT FROZEN

Authority must be explicit and multidimensional.

Initial dimensions to enumerate:

- observe
- propose
- qualify
- authorize
- canonicalize
- project
- execute
- revoke
- migrate
- reconstruct
- attest
- administer

No component receives authority merely because it can observe state.

No component may both propose and authorize the same consequential transition without an explicitly modeled independent authority boundary.

No cognition provider owns canonical truth.
